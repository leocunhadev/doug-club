# Dossiês Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the real `/membros/mentor/dossies` page (closes GitHub issue #32): the mentor's tool for tracking each CLUB member — a "fio da mentoria" (note timeline) and an editable "compromisso ativo" (active commitment) per mentorado. Desbloqueia issue #33 (Radar do dia).

**Architecture:** No mentor↔mentorado link table — every `tier=club` user is an implicit mentorado of the single mentor, same simplification as Agenda (#20), Cofre (#22), Pessoas (#23). Two new standalone models: `MentorNote` (append-only timeline, `member_id`+`mentor_id` both explicit FK) and `MentorCommitment` (one row per member, unique `member_id`, always upserted — no history). The whole feature lives in one mentor-only Livewire page (`tier:mentor` gate) — no Filament resource, matching the existing Disponibilidade/Conteudo pattern rather than Cofre's (which needed Filament for file uploads).

**Tech Stack:** Laravel 13, Livewire 3, Tailwind CSS v3, PHPUnit (`php artisan test`), SQLite (`:memory:` in tests).

**Spec:** `docs/superpowers/specs/2026-08-30-dossies-design.md`

## Global Constraints

- No mentor↔mentorado relationship table — the mentorado list is `User::where('tier', 'club')`, resolved fresh every time, no enrollment step.
- `mentor_id` on `MentorNote` is always `Auth::id()` directly (the mentor IS the logged-in user on this `tier:mentor`-gated page) — never resolved via `User::where('tier', 'mentor')->first()` the way member-facing features do.
- `MentorCommitment.member_id` is unique — saving is always `updateOrCreate`, never accumulates history.
- Notes require both a title and a body (two required fields), not the prototype's single free-text field.
- No `.btn`/`.btn.solid` prototype CSS classes — buttons use plain Tailwind utilities.
- Dates on notes render as `d/m/Y` (numeric), never a Portuguese month abbreviation — `APP_LOCALE` is `en` and no other real page in this app formats a date with a spelled-out month.
- `selectMember($memberId)` re-validates the target is an actual `tier=club` user server-side before changing selection — the Livewire payload is client-controlled.

    use RefreshDatabase;

        $mentor = User::factory()->create(['tier' => 'mentor']);

```php
<?php

namespace App\Livewire\Membros;

use App\Livewire\Concerns\ComputesUserInitials;
use App\Models\MentorCommitment;
use App\Models\MentorNote;
use App\Models\User;
use Illuminate\Support\Facades\Auth;
use Livewire\Attributes\Computed;
use Livewire\Attributes\Layout;
use Livewire\Component;

#[Layout('layouts.membros')]
class Dossies extends Component
{
    use ComputesUserInitials;

    public ?int $selectedMemberId = null;

    public string $noteTitle = '';

    public string $noteBody = '';

    public string $commitmentInput = '';

    public function mount(): void
    {
        $this->selectedMemberId = $this->members->first()?->id;
        $this->loadCommitmentInput();
    }

    #[Computed]
    public function members()
    {
        return User::query()
            ->where('tier', 'club')
            ->orderBy('name')
            ->get();
    }

    #[Computed]
    public function selectedMember(): ?User
    {
        return $this->members->firstWhere('id', $this->selectedMemberId);
    }

    #[Computed]
    public function notes()
    {
        return MentorNote::query()
            ->where('member_id', $this->selectedMemberId)
            ->orderByDesc('created_at')
            ->get();
    }

    public function selectMember(int $memberId): void
    {
        if (! $this->members->contains('id', $memberId)) {
            return;
        }

        $this->selectedMemberId = $memberId;
        $this->reset('noteTitle', 'noteBody');
        $this->loadCommitmentInput();
    }

    public function addNote(): void
    {
        $this->validate([
            'noteTitle' => ['required', 'string', 'max:255'],
            'noteBody' => ['required', 'string', 'max:2000'],
        ]);

        MentorNote::create([
            'member_id' => $this->selectedMemberId,
            'mentor_id' => Auth::id(),
            'title' => $this->noteTitle,
            'body' => $this->noteBody,
        ]);

        $this->reset('noteTitle', 'noteBody');
    }

    public function saveCommitment(): void
    {
        $this->validate([
            'commitmentInput' => ['nullable', 'string', 'max:500'],
        ]);

        MentorCommitment::updateOrCreate(
            ['member_id' => $this->selectedMemberId],
            ['text' => trim($this->commitmentInput) ?: null],
        );
    }

    private function loadCommitmentInput(): void
    {
        $this->commitmentInput = MentorCommitment::query()
            ->where('member_id', $this->selectedMemberId)
            ->value('text') ?? '';
    }

    public function render()
    {
        return view('livewire.membros.dossies');
    }
}
```
