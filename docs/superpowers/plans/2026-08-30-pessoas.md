# Pessoas do CLUB Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the real `/membros/pessoas` page (closes GitHub issue #23): a listing of CLUB members with a self-edited network profile (company, bio, teach/learn tags) and a "request the bridge" action the mentor sees.

**Architecture:** Network-profile fields (`company`, `bio`, `teach_tags`, `learn_tags`) live directly on `users` — the member edits them in a new section of the existing account-settings page (`/profile`), reusing its Volt component. `BridgeRequest` is a standalone model (own migration, own Filament resource, list-only like `MentorSessionResource`) recording who asked to be introduced to whom; no status field — the mentor "resolves" a request by deleting it in Filament. The `/membros/pessoas` Livewire page lists every `tier=club` user except the logged-in member, with incomplete profiles shown with placeholders rather than hidden.

**Tech Stack:** Laravel 13, Livewire 3 (+ Volt for the profile page), Filament 4, Tailwind CSS v3, PHPUnit (`php artisan test`), SQLite (`:memory:` in tests).

**Spec:** `docs/superpowers/specs/2026-08-30-pessoas-design.md`

## Global Constraints

- The member edits their own network profile — never curated by the mentor, never mocked.
- Tags are free text separated by commas, stored as a JSON array (`teach_tags`/`learn_tags`), re-joined with `", "` when reloaded into the edit form.
- No real matching in this version — `/membros/pessoas` is a plain listing (all `tier=club` users except the viewer), no search/filter/suggestion.
- Incomplete profiles still appear in the listing, with a placeholder string in place of whatever is missing (empty company just omits its line; empty bio/tags show a placeholder sentence) — never filtered out.
- `BridgeRequest` has no status field. The Filament resource is list-only (no create/edit forms, mirrors `MentorSessionResource`) with a `DeleteAction` as the only "resolve" mechanism.
- The "Perfil na rede CLUB" section on `/profile` only renders for `auth()->user()->tier === 'club'`.
- `requestBridge($targetId)` on the `Pessoas` Livewire component re-validates the target server-side (not self, must be `tier=club`, not already requested) — the Livewire payload is client-controlled, so the view's own filtering can't be trusted as the only guard.
- No `.btn`/`.btn.solid` prototype classes — every real button in this app already uses plain Tailwind utilities (`rounded-full bg-black text-white`, `disabled:opacity-40 disabled:cursor-not-allowed`), matching `framework-card.blade.php`/`nps-modal.blade.php`.

```php
    /**
     * Update the network-profile fields (company, bio, teach/learn tags).
     */
    public function updateNetworkProfile(): void
    {
        $validated = $this->validate([
            'company' => ['nullable', 'string', 'max:255'],
            'bio' => ['nullable', 'string', 'max:500'],
            'teachTagsInput' => ['nullable', 'string', 'max:255'],
            'learnTagsInput' => ['nullable', 'string', 'max:255'],
        ]);

        $user = Auth::user();
        $user->company = $validated['company'] ?: null;
        $user->bio = $validated['bio'] ?: null;
        $user->teach_tags = $this->parseTags($validated['teachTagsInput']);
        $user->learn_tags = $this->parseTags($validated['learnTagsInput']);
        $user->save();

        $this->dispatch('network-profile-updated');
    }

    /**
     * Split a comma-separated tag string into a trimmed, non-empty array.
     */
    private function parseTags(?string $input): array
    {
        return collect(explode(',', $input ?? ''))
            ->map(fn (string $tag) => trim($tag))
            ->filter()
            ->values()
            ->all();
    }
```

```php
<?php

namespace App\Livewire\Membros;

use App\Livewire\Concerns\ComputesUserInitials;
use App\Models\BridgeRequest;
use App\Models\User;
use Illuminate\Support\Facades\Auth;
use Livewire\Attributes\Computed;
use Livewire\Attributes\Layout;
use Livewire\Component;

#[Layout('layouts.membros')]
class Pessoas extends Component
{
    use ComputesUserInitials;

    #[Computed]
    public function members()
    {
        return User::query()
            ->where('tier', 'club')
            ->where('id', '!=', Auth::id())
            ->orderBy('name')
            ->get();
    }

    #[Computed]
    public function requestedTargetIds(): array
    {
        return BridgeRequest::query()
            ->where('requester_id', Auth::id())
            ->pluck('target_id')
            ->all();
    }

    public function requestBridge(int $targetId): void
    {
        if ($targetId === Auth::id()) {
            return;
        }

        $isClubMember = User::query()
            ->where('id', $targetId)
            ->where('tier', 'club')
            ->exists();

        if (! $isClubMember) {
            return;
        }

        if (in_array($targetId, $this->requestedTargetIds, true)) {
            return;
        }

        BridgeRequest::create([
            'requester_id' => Auth::id(),
            'target_id' => $targetId,
        ]);
    }

    public function render()
    {
        return view('livewire.membros.pessoas');
    }
}
```
