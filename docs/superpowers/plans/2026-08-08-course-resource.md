# CourseResource Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Filament `CourseResource` giving admins full CRUD over `Course` records at `/admin/courses`, per issue #16 (sub-issue 2/3 of #11).

**Architecture:** Scaffold the resource with Filament's own generator (`php artisan make:filament-resource Course --generate`), which introspects the `courses` table and produces a form/table matching the columns exactly. Then hand-edit only the generated table file to: drop the `created_at`/`updated_at` columns (out of the issue's stated scope), add a `lessons_count` column, and make the list drag-reorderable in the same `position desc` order the public site already uses. No hand-written resource/form/page code — those come out of the generator correct as-is.

**Tech Stack:** Filament 4.12 (`Filament\Schemas\Schema`, `Filament\Tables\Table`, `Filament\Actions\*`), installed and gated by `is_admin` in issue #15. Tests use `Livewire::test()` against the generated page classes, per Filament's own testing helpers (`fillForm`, `assertCanSeeTableRecords`, `callTableAction`), matching the existing PHPUnit-style test structure (`tests/Feature/Admin/PanelAccessTest.php`).

## Global Constraints

- Resource covers `Course` only — no `Lesson`/`LessonMaterial` UI (that's issue #17).
- Filament UI stays in Filament's default English (no translation) — explicit product decision for this sub-issue.
- Table's reorder/default sort must be `position` **desc**, matching `Course::lessons()` and the public homepage ordering (`orderByDesc('position')`) — use `reorderable('position', direction: 'desc')`, not the Filament default (`asc`), or dragging a course to the top of the admin list would silently push it to the bottom of the public site.
- Record title attribute is `label`, not `title` — the seeded "Boas Vindas" course has `title => ''`, so `title` can't reliably label the record in breadcrumbs/delete-confirmation modals.
- Table columns are exactly: `label`, `title`, `position`, lesson count. Do not keep the generator's default `created_at`/`updated_at` columns.
- Full suite (`php artisan test`) must stay green when this task is done.

Read `app/Filament/Resources/Courses/Tables/CoursesTable.php` first — it was just generated and will look like this:

```php
<?php

namespace App\Filament\Resources\Courses\Tables;

use Filament\Actions\BulkActionGroup;
use Filament\Actions\DeleteBulkAction;
use Filament\Actions\EditAction;
use Filament\Tables\Columns\TextColumn;
use Filament\Tables\Table;

class CoursesTable
{
    public static function configure(Table $table): Table
    {
        return $table
            ->columns([
                TextColumn::make('label')
                    ->searchable(),
                TextColumn::make('title')
                    ->searchable(),
                TextColumn::make('position')
                    ->numeric()
                    ->sortable(),
                TextColumn::make('created_at')
                    ->dateTime()
                    ->sortable()
                    ->toggleable(isToggledHiddenByDefault: true),
                TextColumn::make('updated_at')
                    ->dateTime()
                    ->sortable()
                    ->toggleable(isToggledHiddenByDefault: true),
            ])
            ->filters([
                //
            ])
            ->recordActions([
                EditAction::make(),
            ])
            ->toolbarActions([
                BulkActionGroup::make([
                    DeleteBulkAction::make(),
                ]),
            ]);
    }
}
```

If the actual generated file differs from this in the `label`/`title`/`position` column
definitions, keep the generator's version of those three columns as-is and apply the same
edits described below relative to the real file. Replace the full file with:

```php
<?php

namespace App\Filament\Resources\Courses\Tables;

use Filament\Actions\BulkActionGroup;
use Filament\Actions\DeleteAction;
use Filament\Actions\DeleteBulkAction;
use Filament\Actions\EditAction;
use Filament\Tables\Columns\TextColumn;
use Filament\Tables\Table;

class CoursesTable
{
    public static function configure(Table $table): Table
    {
        return $table
            ->columns([
                TextColumn::make('label')
                    ->searchable(),
                TextColumn::make('title')
                    ->searchable(),
                TextColumn::make('position')
                    ->numeric()
                    ->sortable(),
                TextColumn::make('lessons_count')
                    ->label('Lessons')
                    ->counts('lessons')
                    ->numeric(),
            ])
            ->defaultSort('position', 'desc')
            ->reorderable('position', direction: 'desc')
            ->filters([
                //
            ])
            ->recordActions([
                EditAction::make(),
                DeleteAction::make(),
            ])
            ->toolbarActions([
                BulkActionGroup::make([
                    DeleteBulkAction::make(),
                ]),
            ]);
    }
}
```

What changed: dropped the `created_at`/`updated_at` columns; added the `lessons_count` column;
added `->defaultSort('position', 'desc')` and `->reorderable('position', direction: 'desc')`
to the table builder chain; added `DeleteAction::make()` to `recordActions` alongside
`EditAction::make()`; added the `DeleteAction` import.

- [ ] **Step 6: Write the feature test**

Create `tests/Feature/Admin/CourseResourceTest.php`:

```php
<?php

namespace Tests\Feature\Admin;

use App\Filament\Resources\Courses\Pages\CreateCourse;
use App\Filament\Resources\Courses\Pages\EditCourse;
use App\Filament\Resources\Courses\Pages\ListCourses;
use App\Models\Course;
use App\Models\User;
use Filament\Actions\DeleteAction;
use Illuminate\Foundation\Testing\RefreshDatabase;
use Livewire\Livewire;
use Tests\TestCase;

class CourseResourceTest extends TestCase
{
    use RefreshDatabase;

    private function admin(): User
    {
        return User::factory()->create(['is_admin' => true]);
    }

    public function test_non_admin_cannot_access_the_courses_list(): void
    {
        $user = User::factory()->create(['is_admin' => false]);

        $response = $this->actingAs($user)->get('/admin/courses');

        $response->assertForbidden();
    }

    public function test_admin_can_see_an_existing_course_in_the_list(): void
    {
        $course = Course::create([
            'label' => 'Módulo 1',
            'title' => 'Fundamentos',
            'description' => null,
            'position' => 10,
        ]);

        $this->actingAs($this->admin());

        Livewire::test(ListCourses::class)
            ->assertCanSeeTableRecords([$course]);
    }

    public function test_admin_can_create_a_course(): void
    {
        $this->actingAs($this->admin());

        Livewire::test(CreateCourse::class)
            ->fillForm([
                'label' => 'Módulo 2',
                'title' => 'Modelos de Negócio',
                'description' => 'Segundo módulo do curso.',
                'position' => 20,
            ])
            ->call('create')
            ->assertHasNoFormErrors();

        $this->assertDatabaseHas('courses', [
            'label' => 'Módulo 2',
            'title' => 'Modelos de Negócio',
            'position' => 20,
        ]);
    }

    public function test_admin_can_edit_a_course(): void
    {
        $course = Course::create([
            'label' => 'Módulo 3',
            'title' => 'Título original',
            'description' => null,
            'position' => 30,
        ]);

        $this->actingAs($this->admin());

        Livewire::test(EditCourse::class, ['record' => $course->getKey()])
            ->fillForm([
                'title' => 'Título atualizado',
            ])
            ->call('save')
            ->assertHasNoFormErrors();

        $this->assertDatabaseHas('courses', [
            'id' => $course->id,
            'title' => 'Título atualizado',
        ]);
    }

    public function test_admin_can_delete_a_course(): void
    {
        $course = Course::create([
            'label' => 'Módulo 4',
            'title' => 'A remover',
            'description' => null,
            'position' => 40,
        ]);

        $this->actingAs($this->admin());

        Livewire::test(ListCourses::class)
            ->callTableAction(DeleteAction::class, record: $course);

        $this->assertDatabaseMissing('courses', ['id' => $course->id]);
    }
}
```
